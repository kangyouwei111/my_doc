# Papertrail 是什么

Papertrail 是一个面向团队的文档工作台模板。它把「知道什么」「为什么这样做」和「下一步怎么做」放在同一个可检索、可评审的空间里。

## 适合记录什么

- **产品与业务共识**：术语、目标、边界与决策背景。
- **工程操作手册**：开发环境、发布流程、故障处理和检查清单。
- **团队运行方式**：会议节奏、职责边界、入职路径与复盘结论。

## 文档的三个层次

| 层次 | 要回答的问题 | 常见内容 |
| --- | --- | --- |
| 事实 | 现在是什么状态？ | 配置、术语、架构图 |
| 决策 | 为什么这样做？ | ADR、取舍、约束 |
| 行动 | 下一步怎么做？ | 指南、清单、命令 |

::: tip 一个简单判断
如果一页文档读完后，读者仍不知道该做什么，可以再补一段「下一步」或一个可复制的示例。
:::
