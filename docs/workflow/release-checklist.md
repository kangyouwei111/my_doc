# 发布检查清单

在合并文档变更前，逐项确认：

- [ ] 标题能准确描述页面要解决的问题
- [ ] 开头说明了读者、目标和前置条件
- [ ] 命令可以从干净环境执行
- [ ] 示例中的版本、路径和链接有效
- [ ] 侧边栏和页面内链接都能打开
- [ ] 没有把敏感信息、令牌或内部地址提交进仓库
- [ ] 在本地运行过 `pnpm build`

## 发布后检查

进入 GitHub Actions，确认 `build` 与 `deploy` 两个阶段都成功。首次启用 Pages 时，在仓库设置中将 Source 设为 **GitHub Actions**。

::: warning 自定义域名
若使用自定义域名，域名解析生效后再添加 `docs/public/CNAME`，否则可能导致预览地址暂时无法访问。
:::
